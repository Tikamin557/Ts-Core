# T's Core

> **This mod is primarily intended for other mods.**
> Most players only need to install it when it is required by another mod.

A shared library for Stardew Valley SMAPI mods.

It provides a collection of APIs and Content Patcher tokens that other mods can use to improve compatibility and reduce duplicated code.

> **Players:** You only need to install this mod if another mod lists it as a requirement.

---

## ✨ Features

- Shared API for other SMAPI mods
- Content Patcher tokens
- Designed to improve compatibility between mods
- Lightweight and safe to leave installed

---

## 📦 Installation

1. Install SMAPI.
2. Download the latest version of T's Core.
3. Extract it into your `Mods` folder.
