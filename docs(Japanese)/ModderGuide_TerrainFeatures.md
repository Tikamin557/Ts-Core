# Terrain Features（地形要素管理）（v1.9.5）

T's Coreに追加された、プレイヤー向けの**地形要素管理メニュー**です。Content Patcherの新しいData Assetや公開APIではありません。

## メニューの開き方

- セーブデータを読み込んでから、**地形要素管理メニュー**のキー（初期値 `L`）を押します。キーはT's CoreのGMCMで変更・解除できます。
- または、T's Coreのショートカットパネルで **Mod機能** から地形要素管理を登録して開きます。
- セーブデータ読み込み後、他のメニューを開いていないときにホスト（メインプレイヤー）が使用できます。

## 対象範囲と項目

処理範囲は**現在のマップ**、または**すべての屋外マップ＋現在のマップ**から選択できます。後者は多数のマップに影響するため、実行前に範囲を確認してください。

個別項目のほか、**すべて**・**Resource Clumps**・**Objects**・**Terrain Features** の一括指定ができます。17種類の選択項目は次のとおりです。

| 分類 | 項目 |
|---|---|
| 地形要素 | Bush、Tree、Grass、Path、Crop、Tilled Soil |
| オブジェクト | Weeds、Twig、Rock、Forage、Fence |
| 大型障害物 | Stump、Log、Boulder |
| 一括指定 | Resource Clumps、Objects、Terrain Features |

**すべて**を選ぶと、一括指定項目を含む17項目すべてが選択されます。

対象項目と処理範囲は `TerrainFeaturesConfig.json` に保存され、次回メニューを開いたときにも引き継がれます。

## 操作

| 操作 | 内容 |
|---|---|
| **Clear** | 選択した地形要素・オブジェクトを削除します。 |
| **Generate** | 再生成元のマップを作成し、配置可能な場所へ選択対象を追加します。 |
| **Reset** | 選択対象を削除してから、再生成元の初期状態に戻します。 |

実行前に確認画面が表示されます。実行後には成功・失敗したマップ数が表示されます。

> **注意：** ClearやResetは選択項目によって既存の地形要素・オブジェクト・作物・設置物を削除する場合があります。実行前にセーブしておくことを推奨します。GenerateやResetは再生成元のマップを作成できない場合、カスタムマップなどで失敗することがあります。プレイヤーが手動で配置した物の復元は保証されません。

## Mod作者向け

この機能はプレイヤー向けのため、現時点ではContent Patcherの登録用Data Assetや公開C# APIは用意されていません。Content Pack側で登録する必要はありません。
